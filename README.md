# pendragon-sandbox

A sandbox for Pendragon RPG tools — built on **Angular 22** and **[Spartan UI](https://spartan.ng)**, styled with the RpgWorld design system.

## Getting started

```bash
npm install
npm start          # http://localhost:4200
npm test           # Vitest unit tests
npm run build      # production build → dist/pendragon-sandbox/browser
```

## Project layout

```
src/
  styles.css                 Tailwind v4 + Spartan preset + RpgWorld theme tokens (light / .dark)
  app/
    app.ts                   Shell: sidebar wrapper, inset header, router outlet
    app.routes.ts
    core/theme/              ThemeService — light/dark, persisted, respects prefers-color-scheme
    layout/app-sidebar/      Collapsible sidebar: brand, navigation, appearance footer
    pages/home/              Home screen (welcome message)
libs/ui/                     Spartan helm components (owned source, generated by the CLI)
components.json              Spartan CLI config (componentsPath, importAlias)
```

### Spartan helm library

Helm components live in `libs/ui/<name>` and are imported through the
`@spartan-ng/helm/<name>` path aliases in `tsconfig.json`. Add more with:

```bash
npx ng g @spartan-ng/cli:ui <component>
```

Installed: `utils`, `button`, `card`, `input`, `separator`, `sheet`, `sidebar`, `skeleton`, `tooltip`.

### Theme

`src/styles.css` maps the RpgWorld design system tokens (warm gold primary,
forest teal secondary, warm neutrals, brick-red destructive) onto Spartan's
semantic CSS variables. Dark mode is the `.dark` class on `<html>` (Spartan's
convention), set by `ThemeService` and by a small inline script in
`index.html` that prevents a flash of the wrong theme. Fonts: Spectral
(display, `font-display`) and Public Sans (UI).

### Icons

[RPG Awesome](https://nagoshiashumari.github.io/Rpg-Awesome/) (`rpg-awesome`, font SIL OFL 1.1 / CSS MIT) is loaded globally via `angular.json`. Use it as `<i class="ra ra-tower" aria-hidden="true"></i>`; the sidebar navigation takes the class name in `navItems` (`icon: 'ra-tower'`). UI icons such as the theme toggle use Lucide through `@ng-icons/lucide`.

The sidebar collapses to icons on desktop (trigger button, rail, or
<kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>B</kbd>) and becomes a sheet on mobile.

## Deploying to GitHub Pages

`.github/workflows/deploy.yml` tests, builds with `--base-href /<repo-name>/`,
copies `index.html` to `404.html` for deep-link fallback, and deploys on every
push to `main` (or manually via _Run workflow_).

`.github/workflows/ci.yml` runs `npm test` and `npm run build` on every pull
request and on pushes to `main`.

One-time setup: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
